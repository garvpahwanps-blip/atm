# Secure ATM and Banking Management System

Java 21, MySQL 8.0.16+ (8.4 recommended), Tomcat 10.1, Jakarta Servlet/JSP, and Swing/AWT.
No Maven, Gradle, frameworks, REST APIs, JSTL, or JUnit. The web and desktop interfaces
share the same model, JDBC DAOs, banking service, and security implementation.

## Final layout

```
src/com/atm/
  model/       User, Account, CustomerSummary, BankTransaction, TransactionType
  dao/         Database, UserDAO, AccountDAO, TransactionDAO
  service/     BankingService, Validation, BankingException,
               InsufficientBalanceException, AccountLockedException, AuthenticationException
  security/    PasswordHasher, AdminPasswordTool, AdminAuthenticator
  servlet/     Web, RegistrationServlet, LoginServlet, DashboardServlet,
               DepositServlet, WithdrawServlet, TransferServlet, StatementServlet,
               ChangePinServlet, LogoutServlet, AdminServlet
  filter/      AuthenticationFilter
  desktop/     AdminDashboard, ClockThread, SessionMonitorThread
webapp/
  index.jsp
  assets/style.css

  WEB-INF/views/  register.jsp, login.jsp, dashboard.jsp, deposit.jsp,
                 withdraw.jsp, transfer.jsp, statement.jsp, change-pin.jsp,

  META-INF/context.xml               # SameSite session cookies
```

JSP views live under WEB-INF so direct requests cannot bypass controllers. Database
configuration and passwords are never included in the WAR or committed to Git.

## 1. IntelliJ and manual libraries

1. Install a JDK **21**, MySQL **8.4**, and Apache Tomcat **10.1** binary distribution
   from their official sites. Verify downloaded archives using publisher checksums.
   Use `java -version` and `javac -version`; a JRE alone is insufficient.
2. Open this directory in IntelliJ as a plain Java project. In **File > Project
   Structure > Project**, select JDK 21 and language level 21. Mark `src` as Sources
   and `tests` as Test Sources. Do not mark `resources` as a deployment resource root.
3. Download MySQL Connector/J **9.4.0** from MySQL's official Connector/J downloads,
   or download the official artifact at
   `https://repo.maven.apache.org/maven2/com/mysql/mysql-connector-j/9.4.0/mysql-connector-j-9.4.0.jar`.
   This is a manual JAR download, not use of Maven. Put the JAR in `lib/`.
4. In **Project Structure > Modules > Dependencies > + > JARs or directories**, add
   that JAR and `TOMCAT_HOME/lib/servlet-api.jar`. Use **Provided** scope for the
   Servlet API. Tomcat supplies Jakarta Servlet 6; `javax.servlet.*` is incompatible.
5. Set `JAVA_HOME` to your JDK 21 and `TOMCAT_HOME` to the extracted Tomcat directory.
   On Linux/macOS add `$JAVA_HOME/bin` to PATH. The scripts use Bash; on Windows use
   Git Bash, or the equivalent `javac`/`jar` commands with `;` classpath separators.

## 2. MySQL and local configuration

Run `mysql -u root -p < database/schema.sql`. In an administrator MySQL shell,
create a local application login, choosing your own strong password:

```sql
CREATE USER 'atm_app'@'127.0.0.1' IDENTIFIED BY '<choose a strong password>';
GRANT SELECT, INSERT, UPDATE ON secure_atm.* TO 'atm_app'@'127.0.0.1';
```

Use the appropriate host for your installation (MySQL may match localhost instead).
The application user needs no schema administration or DELETE permission.
Copy `resources/database.properties.example` to `resources/database.properties`.
Set `db.user`, `db.password`, and the JDBC host/port. `chmod 600` the local file on
Unix. Do not commit it. The example's TLS-disabled URL is for loopback development
only; remote databases must use `sslMode=VERIFY_IDENTITY` with trusted certificates,
and `allowPublicKeyRetrieval` should be removed. All database timestamps use UTC.

## 3. Build and set the administrator password

```sh
export JAVA_HOME=/path/to/jdk-21
export PATH="$JAVA_HOME/bin:$PATH"
export TOMCAT_HOME=/path/to/apache-tomcat-10.1.x
bash scripts/build.sh
java -cp build/classes com.atm.security.AdminPasswordTool
```

The password tool prompts on a real console without echo and emits a PBKDF2 hash
(never the password). Put its output in the local `admin.passwordHash` property.
The administrator login name is `admin`. Use a long, unique password of at least
12 characters. Missing admin configuration disables admin access. Both interfaces
apply an administrator login throttle and idle expiry; web administration also
requires authentication and CSRF tokens.

## 4. Deploy to Tomcat

```sh
export CATALINA_OPTS="-Datm.config=$PWD/resources/database.properties"
cp build/atm.war "$TOMCAT_HOME/webapps/atm.war"
"$TOMCAT_HOME/bin/catalina.sh" run
```

Set the absolute `-Datm.config=...` JVM option in IntelliJ's Tomcat run configuration,
or in a private Tomcat `bin/setenv.sh` for background startup. Do not put credentials
in command arguments. IntelliJ Ultimate can deploy `build/atm.war` under context
`/atm`; Community Edition can use the external Tomcat commands above.
Open the local Tomcat `/atm/` context in your own development environment. Register
a customer, record the generated 12-digit number, log in, deposit, withdraw,
transfer to a second registered customer, and inspect the last ten transactions.
Enable HTTPS and secure cookies before any nonlocal deployment. Do not expose this
development Tomcat or MySQL publicly. Logout uses POST and invalidates the session.

## 5. Swing administrator

```sh
bash scripts/run-admin.sh
```

The launcher reads the same local properties and shared classes as Tomcat. Sign in
as admin. Search by full account number, select a customer, inspect history, and
unlock accounts. Refresh and unlock beep after success. Desktop access requires
a graphical display. Clock and inactivity threads update Swing using the EDT and
are interrupted and joined when the frame closes. Idle expiry returns to login.

## 6. Verification, module by module

1. **Shared security/models:** `bash scripts/test.sh unit` verifies hashing, salt
   uniqueness, invalid PINs/money/names, tampered hashes, and thread shutdown.
2. **JDBC/service:** initialize MySQL, then `bash scripts/test.sh integration`.
   This creates uniquely named test customers in the selected database and leaves
   them for audit. Prefer a dedicated test database configured with
   `ATM_CONFIG=/absolute/path/to/test-database.properties`. Checks cover registration,
   login/lock/unlock, PIN change, deposits, overdrafts, paired transfer entries,
   rollback, and concurrent withdrawal/transfer consistency.
3. **Web:** build/deploy the WAR, then `bash scripts/test.sh web` while Tomcat runs.
   `ATM_BASE_URL` defaults to `http://127.0.0.1:8080/atm`. The Java HTTP test checks
   protected routes, registration, login, session fixation protection, CSRF,
   deposit, withdrawal, transfer, mini statement, PIN changes, and logout.
4. **Desktop:** `bash scripts/test.sh desktop` opens and closes the actual Swing
   frame and tests session expiry; requires a display (or `xvfb-run` on Linux).
   Also manually verify table selection, history, clock updates, unlock, and beep.

`scripts/build.sh` compiles every source with `javac --release 21`, compiles manual
tests, and packages `build/atm.war` with only shared classes and Connector/J. Test
classes and local configuration are excluded. Rebuild and redeploy after edits.
No application source or credentials are generated during environment startup.

## Banking and security behavior

All money uses BigDecimal and decimal SQL columns. Amounts must be positive with
at most two fractional digits and a maximum of 1,000,000,000 per operation. Accounts
start at zero. Registration, authentication state, deposits, withdrawals, PIN
changes, unlocks, and transfers use database transactions. Transfers lock account
rows in ascending ID order with SELECT FOR UPDATE and commit both ledger entries
and balances together. Every ledger row has a unique UUID reference; a transfer's
two references share a UUID and use `-D`/`-C` suffixes for reconciliation.

PINs use PBKDF2WithHmacSHA256, 600,000 iterations, a random 16-byte salt and
constant-time comparison; the versioned hash field includes the salt and cost.
Three wrong PIN attempts lock the account, including wrong current PIN attempts
during PIN changes. Admin unlock resets the counter. Locked customers cannot
perform authenticated operations; inbound transfers can still be received.
SecureRandom generates 12-digit account numbers; a database unique constraint and
bounded retries handle collisions. Session IDs rotate on login; mutation endpoints
require POST and a session CSRF token. JSP output is HTML-escaped in view models.
Session cookies are HttpOnly, cookie-only sessions expire after 10 idle minutes,
and responses prohibit caching and embedding. Database errors are logged on the
server and return generic messages to users.

This implements the requested educational banking workflow. Deposits are simulated
cash credits; real settlement, regulatory controls, distributed admin throttling,
and production operational controls require separate product design.

## Prepared cloud workspace

In the prepared cloud machine, run `source /workspace/.atm-state/env.sh` to activate
the installed JDK 21 and Tomcat paths. Start or restore the local MySQL and Tomcat
services with `bash /workspace/.atm-state/start-services.sh`. MySQL data is stored
under `/workspace/.atm-state/mysql` and survives container recreation. No passwords
are included in source or artifacts. The generated development admin password is
kept in `/workspace/.atm-state/admin-password.txt` with owner-only permissions;
replace it using AdminPasswordTool when desired. The login name is `admin`.

The cloud validation uses a virtual display for desktop tests:
`DISPLAY=:99 ATM_TEST_ADMIN_PASSWORD_FILE=/workspace/.atm-state/admin-password.txt bash scripts/test.sh desktop`.
Authenticated web admin tests use the same password-file variable. Customer test
data is deliberately retained in the development database. Publishing the environment
and validating a newly restored task are separate platform steps.

-- MySQL 8.0.16+ / 8.4. Run as a database administrator, then grant the
-- application user SELECT, INSERT, UPDATE on secure_atm.* (no DDL or DELETE).
CREATE DATABASE IF NOT EXISTS secure_atm CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
USE secure_atm;

CREATE TABLE IF NOT EXISTS users (
    user_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    full_name VARCHAR(100) NOT NULL,
    account_number CHAR(12) CHARACTER SET ascii COLLATE ascii_bin NOT NULL,
    pin_hash VARCHAR(255) CHARACTER SET ascii NOT NULL,
    failed_attempts INT NOT NULL DEFAULT 0,
    locked BOOLEAN NOT NULL DEFAULT FALSE,
    created_at TIMESTAMP(6) NOT NULL DEFAULT CURRENT_TIMESTAMP(6),
    CONSTRAINT uq_users_account_number UNIQUE (account_number),
    CONSTRAINT ck_account_number CHECK (account_number REGEXP '^[0-9]{12}$'),
    CONSTRAINT ck_failed_attempts CHECK (failed_attempts BETWEEN 0 AND 3)
) ENGINE=InnoDB;

CREATE TABLE IF NOT EXISTS accounts (
    account_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    balance DECIMAL(19,2) NOT NULL DEFAULT 0.00,
    account_type VARCHAR(20) NOT NULL DEFAULT 'SAVINGS',
    CONSTRAINT uq_accounts_user UNIQUE (user_id),
    CONSTRAINT fk_accounts_user FOREIGN KEY (user_id) REFERENCES users(user_id),
    CONSTRAINT ck_balance CHECK (balance >= 0),
    CONSTRAINT ck_account_type CHECK (account_type IN ('SAVINGS'))
) ENGINE=InnoDB;

CREATE TABLE IF NOT EXISTS bank_transactions (
    transaction_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    account_id BIGINT NOT NULL,
    type VARCHAR(20) NOT NULL,
    amount DECIMAL(19,2) NOT NULL,
    counterparty_account_number CHAR(12) CHARACTER SET ascii NULL,
    reference_number VARCHAR(40) CHARACTER SET ascii COLLATE ascii_bin NOT NULL,
    balance_after DECIMAL(19,2) NOT NULL,
    notes VARCHAR(255) NOT NULL DEFAULT '',
    created_at TIMESTAMP(6) NOT NULL DEFAULT CURRENT_TIMESTAMP(6),
    CONSTRAINT fk_transactions_account FOREIGN KEY (account_id) REFERENCES accounts(account_id),
    CONSTRAINT uq_transaction_reference UNIQUE (reference_number),
    CONSTRAINT ck_transaction_type CHECK (type IN ('DEPOSIT','WITHDRAWAL','TRANSFER_OUT','TRANSFER_IN')),
    CONSTRAINT ck_transaction_amount CHECK (amount > 0),
    CONSTRAINT ck_transaction_balance CHECK (balance_after >= 0),
    INDEX ix_transactions_recent (account_id, created_at DESC, transaction_id DESC)
) ENGINE=InnoDB;

package com.atm.dao;

import com.atm.model.Account;
import com.atm.model.CustomerSummary;
import java.math.BigDecimal;
import java.sql.*;
import java.util.ArrayList;
import java.util.List;

public final class AccountDAO {
    private static final String SUMMARY = "SELECT u.user_id,u.full_name,u.account_number,u.locked,u.failed_attempts,a.account_id,a.balance FROM users u JOIN accounts a ON a.user_id=u.user_id";
    public void insert(Connection c, long userId) throws SQLException {
        try (PreparedStatement ps = c.prepareStatement("INSERT INTO accounts(user_id,balance,account_type) VALUES(?,0.00,'SAVINGS')")) {
            ps.setLong(1, userId); ps.executeUpdate();
        }
    }
    public Account findByUser(Connection c, long userId, boolean lock) throws SQLException {
        try (PreparedStatement ps = c.prepareStatement("SELECT * FROM accounts WHERE user_id=?" + (lock ? " FOR UPDATE" : ""))) {
            ps.setLong(1, userId);
            try (ResultSet rs = ps.executeQuery()) { return rs.next() ? account(rs) : null; }
        }
    }
    public Account lockById(Connection c, long accountId) throws SQLException {
        try (PreparedStatement ps = c.prepareStatement("SELECT * FROM accounts WHERE account_id=? FOR UPDATE")) {
            ps.setLong(1, accountId);
            try (ResultSet rs = ps.executeQuery()) {
                if (!rs.next()) throw new SQLException("Account missing");
                return account(rs);
            }
        }
    }
    private Account account(ResultSet rs) throws SQLException {
        return new Account(rs.getLong("account_id"), rs.getLong("user_id"), rs.getBigDecimal("balance"), rs.getString("account_type"));
    }
    public void balance(Connection c, long accountId, BigDecimal balance) throws SQLException {
        try (PreparedStatement ps = c.prepareStatement("UPDATE accounts SET balance=? WHERE account_id=?")) {
            ps.setBigDecimal(1, balance); ps.setLong(2, accountId);
            if (ps.executeUpdate() != 1) throw new SQLException("Account missing");
        }
    }
    public CustomerSummary summary(Connection c, long userId) throws SQLException {
        try (PreparedStatement ps = c.prepareStatement(SUMMARY + " WHERE u.user_id=?")) {
            ps.setLong(1, userId);
            try (ResultSet rs = ps.executeQuery()) { return rs.next() ? summary(rs) : null; }
        }
    }
    public List<CustomerSummary> search(Connection c, String number) throws SQLException {
        List<CustomerSummary> result = new ArrayList<>();
        try (PreparedStatement ps = c.prepareStatement(SUMMARY + (number == null ? " ORDER BY u.user_id" : " WHERE u.account_number=?"))) {
            if (number != null) ps.setString(1, number);
            try (ResultSet rs = ps.executeQuery()) { while (rs.next()) result.add(summary(rs)); }
        }
        return List.copyOf(result);
    }
    private CustomerSummary summary(ResultSet rs) throws SQLException {
        return new CustomerSummary(rs.getLong("user_id"), rs.getLong("account_id"), rs.getString("full_name"),
            rs.getString("account_number"), rs.getBigDecimal("balance"), rs.getBoolean("locked"), rs.getInt("failed_attempts"));
    }
}

package com.atm.dao;

import java.io.IOException;
import java.io.InputStream;
import java.nio.file.Files;
import java.nio.file.Path;
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;
import java.util.Properties;

public final class Database {
    @FunctionalInterface
    public interface ConnectionFactory { Connection open() throws SQLException; }
    private Database() {}

    public static Properties configuration() {
        String location = System.getProperty("atm.config");
        if (location == null || location.isBlank()) location = System.getenv("ATM_CONFIG");
        if (location == null || location.isBlank()) location = "resources/database.properties";
        Properties properties = new Properties();
        try (InputStream input = Files.newInputStream(Path.of(location))) { properties.load(input); }
        catch (IOException e) { throw new IllegalStateException("Cannot read local database configuration. Set -Datm.config to its absolute path.", e); }
        return properties;
    }

    public static Connection open() throws SQLException {
        // Tomcat's common class loader cannot discover drivers inside WEB-INF/lib.
        try { Class.forName("com.mysql.cj.jdbc.Driver"); }
        catch (ClassNotFoundException e) { throw new SQLException("Add the MySQL Connector/J JAR to lib and rebuild.", e); }
        Properties p = configuration();
        String url = p.getProperty("db.url", "");
        if (!url.startsWith("jdbc:mysql:")) throw new SQLException("A MySQL JDBC URL is required.");
        Connection connection = DriverManager.getConnection(url, p.getProperty("db.user", ""), p.getProperty("db.password", ""));
        connection.setTransactionIsolation(Connection.TRANSACTION_READ_COMMITTED);
        return connection;
    }
}

package com.atm.dao;

import com.atm.model.*;
import java.math.BigDecimal;
import java.sql.*;
import java.util.ArrayList;
import java.util.List;

public final class TransactionDAO {
    public void insert(Connection c, long accountId, TransactionType type, BigDecimal amount,
                       String counterparty, String reference, BigDecimal balance, String notes) throws SQLException {
        try (PreparedStatement ps = c.prepareStatement("INSERT INTO bank_transactions(account_id,type,amount,counterparty_account_number,reference_number,balance_after,notes) VALUES(?,?,?,?,?,?,?)")) {
            ps.setLong(1, accountId); ps.setString(2, type.name()); ps.setBigDecimal(3, amount);
            ps.setString(4, counterparty); ps.setString(5, reference); ps.setBigDecimal(6, balance); ps.setString(7, notes);
            ps.executeUpdate();
        }
    }
    public List<BankTransaction> history(Connection c, long accountId, int limit) throws SQLException {
        List<BankTransaction> result = new ArrayList<>();
        String sql = "SELECT * FROM bank_transactions WHERE account_id=? ORDER BY created_at DESC,transaction_id DESC";
        // A zero limit denotes complete administrator history; customer statements use 10.
        try (PreparedStatement ps = c.prepareStatement(sql + (limit > 0 ? " LIMIT ?" : ""))) {
            ps.setLong(1, accountId); if (limit > 0) ps.setInt(2, limit);
            try (ResultSet rs = ps.executeQuery()) {
                while (rs.next()) result.add(new BankTransaction(rs.getLong("transaction_id"), accountId,
                    TransactionType.valueOf(rs.getString("type")), rs.getBigDecimal("amount"),
                    rs.getString("counterparty_account_number"), rs.getString("reference_number"),
                    rs.getBigDecimal("balance_after"), rs.getString("notes"), rs.getTimestamp("created_at").toInstant()));
            }
        }
        return List.copyOf(result);
    }
}

package com.atm.dao;

import com.atm.model.User;
import java.sql.*;

public final class UserDAO {
    public User findByNumber(Connection c, String number, boolean forUpdate) throws SQLException {
        return find(c, "SELECT * FROM users WHERE account_number=?" + (forUpdate ? " FOR UPDATE" : ""), number);
    }
    public User findById(Connection c, long id, boolean forUpdate) throws SQLException {
        return find(c, "SELECT * FROM users WHERE user_id=?" + (forUpdate ? " FOR UPDATE" : ""), id);
    }
    private User find(Connection c, String sql, Object key) throws SQLException {

        }
    }

            ps.executeUpdate();

            }
        }
    }

            while (running) {

        finally { running = false; }
    }

import java.util.concurrent.atomic.AtomicBoolean;
import java.util.concurrent.atomic.AtomicLong;
import javax.swing.SwingUtilities;

public final class SessionMonitorThread extends Thread {
    private volatile boolean running = true;
    private final AtomicBoolean active = new AtomicBoolean();
    private final AtomicLong lastActivity = new AtomicLong(System.nanoTime());
    private final long timeoutNanos;
    private final Runnable expire;
    public SessionMonitorThread(Duration timeout, Runnable expire) {
        super("atm-session-monitor");
        if (timeout.isNegative() || timeout.isZero()) throw new IllegalArgumentException("Positive timeout required");
        this.timeoutNanos = timeout.toNanos(); this.expire = expire; setDaemon(true);
    }
    public void touch() { lastActivity.set(System.nanoTime()); }
    public void setActive(boolean value) { touch(); active.set(value); }
    @Override public void run() {
        try {
            while (running) {
                if (active.get() && System.nanoTime() - lastActivity.get() >= timeoutNanos && active.compareAndSet(true, false))
                    SwingUtilities.invokeLater(() -> { if (running && !active.get()) expire.run(); });
                Thread.sleep(50);
            }
        } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
        finally { running = false; }
    }
    public void shutdown() { running = false; interrupt(); }
}

package com.atm.security;

import com.atm.dao.Database;
import java.time.Duration;

/** A process-wide throttle for the single configured administrator. */
public final class AdminAuthenticator {
    private static int failures;
    private static long blockedUntil;
    private AdminAuthenticator() {}

    public static synchronized boolean authenticate(String name, char[] password) {
        long now = System.nanoTime();
        if (blockedUntil != 0 && now < blockedUntil) return false;
        String hash = Database.configuration().getProperty("admin.passwordHash", "");
        boolean verified = PasswordHasher.verify(password, hash);
        if ("admin".equals(name) && verified) { failures = 0; blockedUntil = 0; return true; }
        if (++failures >= 5) { blockedUntil = now + Duration.ofMinutes(1).toNanos(); failures = 0; }
        return false;
    }

    public static int sessionMinutes() {
        try { return Math.max(1, Math.min(60, Integer.parseInt(Database.configuration().getProperty("admin.sessionMinutes", "10")))); }
        catch (NumberFormatException e) { return 10; }
    }
}

package com.atm.security;

import java.security.GeneralSecurityException;
import java.security.MessageDigest;
import java.security.SecureRandom;
import java.util.Arrays;
import java.util.Base64;
import javax.crypto.SecretKeyFactory;
import javax.crypto.spec.PBEKeySpec;

public final class PasswordHasher {
    private static final SecureRandom RANDOM = new SecureRandom();
    private static final int ITERATIONS = 600_000;
    private PasswordHasher() {}

    public static String hash(char[] password) {
        byte[] salt = new byte[16];
        RANDOM.nextBytes(salt);
        byte[] hash = derive(password, salt, ITERATIONS);
        try {
            return "pbkdf2-sha256$" + ITERATIONS + "$" + Base64.getEncoder().encodeToString(salt)
                + "$" + Base64.getEncoder().encodeToString(hash);
        } finally { Arrays.fill(hash, (byte) 0); }
    }

    public static boolean verify(char[] password, String encoded) {
        if (password == null || encoded == null || encoded.length() > 255) return false;
        try {
            String[] parts = encoded.split("\\$", -1);
            if (parts.length != 4 || !parts[0].equals("pbkdf2-sha256")) return false;
            int rounds = Integer.parseInt(parts[1]);
            if (rounds < ITERATIONS || rounds > 2_000_000) return false;
            byte[] salt = Base64.getDecoder().decode(parts[2]);
            byte[] expected = Base64.getDecoder().decode(parts[3]);
            if (salt.length != 16 || expected.length != 32) return false;
            byte[] actual = derive(password, salt, rounds);
            try { return MessageDigest.isEqual(actual, expected); }
            finally { Arrays.fill(actual, (byte) 0); }
        } catch (IllegalArgumentException e) { return false; }
    }

    private static byte[] derive(char[] password, byte[] salt, int rounds) {
        PBEKeySpec spec = new PBEKeySpec(password, salt, rounds, 256);
        try { return SecretKeyFactory.getInstance("PBKDF2WithHmacSHA256").generateSecret(spec).getEncoded(); }
        catch (GeneralSecurityException e) { throw new IllegalStateException("PBKDF2 is unavailable", e); }
        finally { spec.clearPassword(); }
    }
}

package com.atm.service;

import com.atm.dao.*;
import com.atm.model.*;
import com.atm.security.PasswordHasher;
import java.math.BigDecimal;
import java.security.SecureRandom;
import java.sql.*;
import java.util.List;
import java.util.UUID;

public final class BankingService {
    private static final SecureRandom RANDOM = new SecureRandom();
    private static final String DUMMY_HASH = PasswordHasher.hash("0000".toCharArray());
    private final Database.ConnectionFactory connections;
    private final UserDAO users = new UserDAO();
    private final AccountDAO accounts = new AccountDAO();
    private final TransactionDAO transactions = new TransactionDAO();

    public BankingService() { this(Database::open); }
    public BankingService(Database.ConnectionFactory connections) { this.connections = connections; }
    @FunctionalInterface private interface Work<T> { T run(Connection c) throws SQLException; }

    private <T> T transaction(Work<T> work) {
        try (Connection c = connections.open()) {
            c.setAutoCommit(false);
            try {
                T result = work.run(c);
                c.commit();
                return result;
            } catch (SQLException | RuntimeException e) {
                try { c.rollback(); } catch (SQLException rollback) { e.addSuppressed(rollback); }
                throw e;
            }
        } catch (SQLException e) { throw new BankingException("The database operation could not be completed. Please try again.", e); }
    }

    public CustomerSummary register(String fullName, char[] pin) {
        String name = Validation.name(fullName);
        Validation.pin(pin);
        String hash = PasswordHasher.hash(pin);
        for (int retry = 0; retry < 5; retry++) {
            String number = Long.toString(RANDOM.nextLong(100_000_000_000L, 1_000_000_000_000L));
            try {
                return transaction(c -> {
                    long userId = users.insert(c, name, number, hash);
                    accounts.insert(c, userId);
                    return accounts.summary(c, userId);
                });
            } catch (BankingException e) {
                if (!(e.getCause() instanceof SQLException sql) || sql.getErrorCode() != 1062) throw e;
            }
        }
        throw new BankingException("Could not allocate an account number. Please retry.");
    }

    private record AuthenticationResult(CustomerSummary customer, boolean locked) {}

    public CustomerSummary login(String number, char[] pin) {
        Validation.accountNumber(number); Validation.pin(pin);
        AuthenticationResult result = transaction(c -> {
            User user = users.findByNumber(c, number, true);
            if (user == null) { PasswordHasher.verify(pin, DUMMY_HASH); return new AuthenticationResult(null, false); }
            if (user.locked()) return new AuthenticationResult(null, true);
            if (!PasswordHasher.verify(pin, user.pinHash())) return new AuthenticationResult(null, failedPin(c, user));
            users.attempts(c, user.id(), 0, false);
            return new AuthenticationResult(accounts.summary(c, user.id()), false);
        });
        // Fail only after committing the failed-attempt counter.
        if (result.locked()) throw new AccountLockedException();
        if (result.customer() == null) throw new AuthenticationException("Invalid account number or PIN.");
        return result.customer();
    }

    private boolean failedPin(Connection c, User user) throws SQLException {
        int attempts = Math.min(3, user.failedAttempts() + 1);
        users.attempts(c, user.id(), attempts, attempts >= 3);
        return attempts >= 3;
    }
    private User activeUser(Connection c, long userId, boolean lock) throws SQLException {
        User user = users.findById(c, userId, lock);
        if (user == null) throw new AuthenticationException("Please log in again.");
        if (user.locked()) throw new AccountLockedException();
        return user;
    }

    public CustomerSummary customer(long userId) {
        return transaction(c -> { activeUser(c, userId, false); return accounts.summary(c, userId); });
    }

    public String deposit(long userId, BigDecimal input, String inputNotes) {
        BigDecimal amount = Validation.amount(input); String notes = Validation.notes(inputNotes);
        return transaction(c -> {
            activeUser(c, userId, true);
            Account account = accounts.findByUser(c, userId, true);
            BigDecimal after = Validation.credit(account.balance(), amount);
            String reference = UUID.randomUUID().toString();
            accounts.balance(c, account.id(), after);
            transactions.insert(c, account.id(), TransactionType.DEPOSIT, amount, null, reference, after, notes);
            return reference;
        });
    }

    public String withdraw(long userId, BigDecimal input, String inputNotes) {
        BigDecimal amount = Validation.amount(input); String notes = Validation.notes(inputNotes);
        return transaction(c -> {
            activeUser(c, userId, true);
            Account account = accounts.findByUser(c, userId, true);
            if (account.balance().compareTo(amount) < 0) throw new InsufficientBalanceException();
            BigDecimal after = account.balance().subtract(amount);
            String reference = UUID.randomUUID().toString();
            accounts.balance(c, account.id(), after);
            transactions.insert(c, account.id(), TransactionType.WITHDRAWAL, amount, null, reference, after, notes);
            return reference;
        });
    }

    public String transfer(long userId, String destination, BigDecimal input, String inputNotes) {
        Validation.accountNumber(destination);
        BigDecimal amount = Validation.amount(input); String notes = Validation.notes(inputNotes);
        return transaction(c -> {
            User sender = activeUser(c, userId, true);
            if (sender.accountNumber().equals(destination)) throw new BankingException("Choose a different recipient account.");
            User recipient = users.findByNumber(c, destination, false);
            if (recipient == null) throw new BankingException("Recipient account was not found.");
            Account from = accounts.findByUser(c, userId, false);
            Account to = accounts.findByUser(c, recipient.id(), false);
            // Always acquire balance locks in a global order to avoid opposing-transfer deadlocks.
            Account first = accounts.lockById(c, Math.min(from.id(), to.id()));
            Account second = accounts.lockById(c, Math.max(from.id(), to.id()));
            from = first.id() == from.id() ? first : second;
            to = first.id() == to.id() ? first : second;
            if (from.balance().compareTo(amount) < 0) throw new InsufficientBalanceException();
            BigDecimal debit = from.balance().subtract(amount);
            BigDecimal credit = Validation.credit(to.balance(), amount);
            String reference = UUID.randomUUID().toString();
            accounts.balance(c, from.id(), debit);
            accounts.balance(c, to.id(), credit);
            transactions.insert(c, from.id(), TransactionType.TRANSFER_OUT, amount, destination, reference + "-D", debit, notes);
            transactions.insert(c, to.id(), TransactionType.TRANSFER_IN, amount, sender.accountNumber(), reference + "-C", credit, notes);
            return reference + "-D";
        });
    }

    public List<BankTransaction> miniStatement(long userId) {
        return transaction(c -> {
            activeUser(c, userId, false);
            return transactions.history(c, accounts.findByUser(c, userId, false).id(), 10);
        });
    }

    public void changePin(long userId, char[] currentPin, char[] newPin) {
        Validation.pin(currentPin); Validation.pin(newPin);
        if (java.util.Arrays.equals(currentPin, newPin)) throw new BankingException("Choose a different new PIN.");
        int result = transaction(c -> {
            User user = activeUser(c, userId, true);
            if (!PasswordHasher.verify(currentPin, user.pinHash())) return failedPin(c, user) ? 2 : 1;
            users.changePin(c, userId, PasswordHasher.hash(newPin));
            return 0;
        });
        if (result == 2) throw new AccountLockedException();
        if (result == 1) throw new AuthenticationException("Current PIN is incorrect.");
    }

    public List<CustomerSummary> customers(String number) {
        String query = number == null || number.isBlank() ? null : Validation.accountNumber(number);
        return transaction(c -> accounts.search(c, query));
    }
    public List<BankTransaction> adminHistory(String number) {
        Validation.accountNumber(number);
        return transaction(c -> {
            User user = users.findByNumber(c, number, false);
            if (user == null) throw new BankingException("Customer was not found.");
            return transactions.history(c, accounts.findByUser(c, user.id(), false).id(), 0);
        });
    }
    public void unlock(String number) {
        Validation.accountNumber(number);
        transaction(c -> {
            User user = users.findByNumber(c, number, true);
            if (user == null) throw new BankingException("Customer was not found.");
            users.attempts(c, user.id(), 0, false);
            return null;
        });
    }
}

package com.atm.service;

import java.math.BigDecimal;
import java.math.RoundingMode;

public final class Validation {
    public static final BigDecimal MAX_AMOUNT = new BigDecimal("1000000000.00");
    public static final BigDecimal MAX_BALANCE = new BigDecimal("99999999999999999.99");
    private Validation() {}

    public static String name(String value) {
        if (value == null) throw new BankingException("Name is required.");
        String name = value.strip().replaceAll("\\s+", " ");
        if (name.length() < 2 || name.length() > 100 ||
            !name.matches("[\\p{L}\\p{M}][\\p{L}\\p{M} .'-]*"))
            throw new BankingException("Name must contain 2–100 letters, spaces, apostrophes, periods or hyphens.");
        return name;
    }

    public static String accountNumber(String value) {
        if (value == null || !value.matches("[0-9]{12}"))
            throw new BankingException("Account number must contain exactly 12 digits.");
        return value;
    }

    public static void pin(char[] pin) {
        if (pin == null || pin.length != 4) throw new BankingException("PIN must contain exactly four digits.");
        for (char c : pin) if (c < '0' || c > '9')
            throw new BankingException("PIN must contain exactly four digits.");
    }

    public static BigDecimal amount(String value) {
        if (value == null || value.length() > 30 || !value.matches("[0-9]+(\\.[0-9]{1,2})?"))
            throw new BankingException("Enter a positive amount with at most two decimal places.");
        return amount(new BigDecimal(value));
    }

    public static BigDecimal amount(BigDecimal value) {
        if (value == null || value.signum() <= 0 || value.compareTo(MAX_AMOUNT) > 0)
            throw new BankingException("Amount must be between 0.01 and 1,000,000,000.00.");
        try { return value.setScale(2, RoundingMode.UNNECESSARY); }
        catch (ArithmeticException e) { throw new BankingException("Amount must have at most two decimal places."); }
    }

    public static String notes(String value) {
        String notes = value == null ? "" : value.strip();
        if (notes.length() > 255 || notes.chars().anyMatch(Character::isISOControl))
            throw new BankingException("Notes must be at most 255 characters without control characters.");
        return notes;
    }

    public static BigDecimal credit(BigDecimal balance, BigDecimal amount) {
        BigDecimal result = balance.add(amount);
        if (result.compareTo(MAX_BALANCE) > 0) throw new BankingException("Account balance limit exceeded.");
        return result;
    }
}

    @Override protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        boolean authenticated = Boolean.TRUE.equals(req.getSession().getAttribute("admin"));
        req.setAttribute("adminAuthenticated", authenticated);
        if (authenticated) {
            req.setAttribute("customers", BANK.customers(req.getParameter("accountNumber")).stream().map(Web::customerView).toList());
            String selected = req.getParameter("selected");
            if (selected != null && !selected.isBlank()) req.setAttribute("transactions", transactionViews(BANK.adminHistory(selected)));
        }

    }
    @Override protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws IOException {

        if ("login".equals(action)) {
            char[] password = secret(req, "password", 256);
            try {
                if (!AdminAuthenticator.authenticate(req.getParameter("username"), password))
                    throw new AuthenticationException("Administrator login failed or temporarily throttled.");
                rotateSession(req); req.getSession().setAttribute("admin", true);
                req.getSession().setMaxInactiveInterval(AdminAuthenticator.sessionMinutes() * 60);
                success(req, resp, "/admin", "Administrator signed in.");
            } finally { Arrays.fill(password, '\0'); }
            return;

        if (!Boolean.TRUE.equals(req.getSession().getAttribute("admin"))) throw new AuthenticationException("Administrator login required.");
        if ("logout".equals(action)) {
            req.getSession().invalidate(); resp.setStatus(303); resp.setHeader("Location", req.getContextPath() + "/admin");
        } else if ("unlock".equals(action)) {
            BANK.unlock(req.getParameter("accountNumber")); success(req, resp, "/admin", "Account unlocked.");

    }

package com.atm.servlet;

import com.atm.model.*;
import com.atm.service.*;
import jakarta.servlet.*;
import jakarta.servlet.http.*;
import java.io.IOException;
import java.security.SecureRandom;
import java.util.*;

/** Controller helpers and presentation-only mapping shared by servlets. */
public abstract class Web extends HttpServlet {
    protected static final BankingService BANK = new BankingService();
    private static final SecureRandom RANDOM = new SecureRandom();

    @Override protected void service(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        try { super.service(req, resp); }
        catch (BankingException e) {
            if (e.getCause() != null) getServletContext().log("Banking operation failed", e);
            if (e instanceof AccountLockedException) req.getSession().removeAttribute("userId");
            error(req, resp, e instanceof AuthenticationException ? 401 : 400, e.getMessage());
        } catch (RuntimeException e) {
            getServletContext().log("Unexpected application failure", e);
            error(req, resp, 500, "The operation could not be completed. Please try again later.");
        }
    }

    public static String escape(Object value) {
        return value == null ? "" : value.toString().replace("&", "&amp;").replace("<", "&lt;")
            .replace(">", "&gt;").replace("\"", "&quot;").replace("'", "&#39;");
    }
    public static String csrf(HttpServletRequest req) {
        HttpSession session = req.getSession();
        String token = (String) session.getAttribute("csrf");
        if (token == null) {
            byte[] bytes = new byte[32]; RANDOM.nextBytes(bytes);
            token = Base64.getUrlEncoder().withoutPadding().encodeToString(bytes);
            session.setAttribute("csrf", token);
        }
        return token;
    }
    public static void view(HttpServletRequest req, HttpServletResponse resp, String page) throws ServletException, IOException {
        req.setAttribute("context", req.getContextPath());
        req.setAttribute("csrf", csrf(req));
        Object flash = req.getSession().getAttribute("flash");
        req.setAttribute("message", escape(flash)); req.getSession().removeAttribute("flash");
        req.getRequestDispatcher("/WEB-INF/views/" + page + ".jsp").forward(req, resp);
    }
    public static void error(HttpServletRequest req, HttpServletResponse resp, int code, String message) throws ServletException, IOException {
        resp.setStatus(code); req.setAttribute("error", escape(message)); view(req, resp, "error");
    }
    protected static long userId(HttpServletRequest req) {
        Object id = req.getSession().getAttribute("userId");
        if (!(id instanceof Long userId)) throw new AuthenticationException("Please log in again.");
        return userId;
    }
    protected static void rotateSession(HttpServletRequest req) {
        req.getSession().invalidate(); req.getSession(true); req.changeSessionId(); csrf(req);
    }
    protected static void success(HttpServletRequest req, HttpServletResponse resp, String path, String message) throws IOException {
        req.getSession().setAttribute("flash", message);
        resp.setStatus(303); resp.setHeader("Location", req.getContextPath() + path);
    }
    protected static char[] secret(HttpServletRequest req, String name, int max) {
        String value = req.getParameter(name);
        if (value == null || value.length() > max) throw new BankingException("Invalid secret input.");
        return value.toCharArray();
    }
    protected static Map<String, String> customerView(CustomerSummary c) {
        return Map.of("name", escape(c.fullName()), "number", c.accountNumber(), "balance", c.balance().toPlainString(),
            "status", c.locked() ? "Locked" : "Active", "attempts", Integer.toString(c.failedAttempts()));
    }
    protected static List<Map<String, String>> transactionViews(List<BankTransaction> transactions) {
        return transactions.stream().map(t -> Map.of("time", escape(t.createdAt()), "type", t.type().name(),
            "amount", t.amount().toPlainString(), "counterparty", escape(t.counterpartyAccountNumber()),
            "reference", escape(t.referenceNumber()), "balance", t.balanceAfter().toPlainString(), "notes", escape(t.notes()))).toList();
    }
}

    private static <T extends Component> T find(Container root, Class<T> type, String text) {
        for (Component c : root.getComponents()) {
            if (type.isInstance(c) && (text == null || (c instanceof AbstractButton b && text.equals(b.getText())))) return type.cast(c);
            if (c instanceof Container nested) { T found = find(nested, type, text); if (found != null) return found; }
        }
        return null;
    }
    private static void waitFor(Callable<Boolean> condition, String description) throws Exception {
        long end = System.nanoTime() + TimeUnit.SECONDS.toNanos(12);
        while (System.nanoTime() < end) {
            AtomicReference<Boolean> ok = new AtomicReference<>(false);
            SwingUtilities.invokeAndWait(() -> { try { ok.set(condition.call()); } catch (Exception e) { throw new RuntimeException(e); } });
            if (ok.get()) return;
            Thread.sleep(50);
        }
        throw new AssertionError("Timed out: " + description);
    }
    public static void main(String[] args) throws Exception {
        if (GraphicsEnvironment.isHeadless()) throw new IllegalStateException("Graphical display required; use xvfb-run on Linux");

public final class ThreadTest {
    public static void main(String[] args) throws Exception {
        CountDownLatch tick = new CountDownLatch(1), expired = new CountDownLatch(1);
        AtomicBoolean safeClock = new AtomicBoolean(), safeExpiry = new AtomicBoolean();
        ClockThread clock = new ClockThread(text -> { safeClock.set(SwingUtilities.isEventDispatchThread() && !text.isBlank()); tick.countDown(); });
        SessionMonitorThread monitor = new SessionMonitorThread(Duration.ofMillis(150), () -> { safeExpiry.set(SwingUtilities.isEventDispatchThread()); expired.countDown(); });
        clock.start(); monitor.start(); monitor.setActive(true);
        try {
            if (!tick.await(3, TimeUnit.SECONDS) || !expired.await(3, TimeUnit.SECONDS) || !safeClock.get() || !safeExpiry.get())
                throw new AssertionError("Clock and timeout callbacks must run on the EDT");
        } finally { clock.shutdown(); monitor.shutdown(); clock.join(1000); monitor.join(1000); }
        if (clock.isAlive() || monitor.isAlive()) throw new AssertionError("Threads did not terminate");
        System.out.println("Thread tests: clock, idle expiry, EDT safety, clean shutdown passed");
    }
}

public final class WebSmokeTest {
    private final CookieManager cookies = new CookieManager(null, CookiePolicy.ACCEPT_ALL);
    private final HttpClient client = HttpClient.newBuilder().cookieHandler(cookies).connectTimeout(Duration.ofSeconds(5)).build();
    private final String base = System.getenv().getOrDefault("ATM_BASE_URL", "http://127.0.0.1:8080/atm");
    private int checks;
    private void check(boolean condition, String message) {
        if (!condition) throw new AssertionError(message);
        checks++;
    }
    private HttpResponse<String> get(String path) throws Exception {
        return client.send(HttpRequest.newBuilder(URI.create(base + path)).timeout(Duration.ofSeconds(20)).GET().build(), HttpResponse.BodyHandlers.ofString());
    }
    private HttpResponse<String> post(String path, Map<String,String> values) throws Exception {
        StringJoiner body = new StringJoiner("&");
        values.forEach((key, value) -> body.add(URLEncoder.encode(key, StandardCharsets.UTF_8) + "=" + URLEncoder.encode(value, StandardCharsets.UTF_8)));
        return client.send(HttpRequest.newBuilder(URI.create(base + path)).timeout(Duration.ofSeconds(20))
            .header("Content-Type", "application/x-www-form-urlencoded").POST(HttpRequest.BodyPublishers.ofString(body.toString())).build(), HttpResponse.BodyHandlers.ofString());
    }
    private String token(String path) throws Exception {
        var response = get(path);
        check(response.statusCode() == 200, "GET " + path + " returned " + response.statusCode());
        Matcher matcher = Pattern.compile("name=\"csrf\" value=\"([^\"]+)\"").matcher(response.body());
        if (!matcher.find()) throw new AssertionError("No CSRF token on " + path);
        return matcher.group(1);
    }
    private String register(String name, String pin) throws Exception {
        check(post("/register", Map.of("csrf", token("/register"), "name", name, "pin", pin)).statusCode() == 303, "Registration");
        String body = get("/login").body();
        Matcher number = Pattern.compile("account number is ([0-9]{12})").matcher(body);
        if (!number.find()) throw new AssertionError("Missing generated account number");
        return number.group(1);
    }
    private String sessionId() {
        return cookies.getCookieStore().getCookies().stream().filter(c -> c.getName().equals("JSESSIONID")).findFirst().orElseThrow().getValue();
    }
    private void run() throws Exception {
        check(get("/").statusCode() == 200, "Landing page");
        for (String route : List.of("/dashboard", "/deposit", "/withdraw", "/transfer", "/statement", "/change-pin"))
            check(get(route).statusCode() == 302, "Protect " + route);
        check(get("/WEB-INF/views/dashboard.jsp").statusCode() == 404, "Protect direct JSP access");
        check(post("/register", Map.of("name", "Forged Request", "pin", "1111")).statusCode() == 403, "Registration CSRF");

        String sender = register("Web Customer", "1234");
        String csrf = token("/login"), originalSession = sessionId();

        check(!originalSession.equals(sessionId()), "Rotate login session ID");

        check(dashboard.statusCode() == 200 && dashboard.body().contains(sender) && dashboard.body().contains("Web Customer"), "Dashboard data");
        check(dashboard.headers().firstValue("Cache-Control").orElse("").contains("no-store"), "No cache");
        check(dashboard.headers().firstValue("Content-Security-Policy").isPresent(), "CSP");
        check(post("/deposit", Map.of("csrf", csrf, "amount", "1")).statusCode() == 403, "Old session token rejected");
        csrf = token("/deposit");

        dashboard = get("/dashboard");
        check(dashboard.body().contains("100.25"), "Deposited balance");

        check(post("/logout", Map.of("csrf", token("/dashboard"))).statusCode() == 303, "Logout");
